Molang, do zero

A linguagem de expressões do Minecraft Bedrock, explicada em 8 lições curtas com exemplos e exercícios. Serve para animações, texturas, partículas e comportamentos de add-ons.

Lição 1: O que é Molang e onde ele é usado

Molang não é uma linguagem completa como Python. É uma linguagem de expressões: você escreve uma conta ou condição e ela devolve um valor (número, verdadeiro/falso ou texto).

Onde aparece

  • Animações (animations/*.json): mover ossos conforme velocidade, tempo etc.
  • Animation Controllers: trocar de estado (parado, andando, atacando).
  • Render Controllers: escolher textura, modelo ou material por condição.
  • Partículas: cor, tamanho, direção e quantidade.
  • Behavior Packs: filtros, eventos e propriedades de entidades.

Regras básicas de sintaxe

  • Não diferencia maiúsculas de minúsculas (Math.Sin = math.sin).
  • Com mais de uma instrução, cada uma termina em ;.
  • Números são decimais: 1, 0.5, -3.
  • true vale 1 e false vale 0.
  • Textos usam aspas simples: 'texto'.

O exemplo mais simples, dentro de um JSON:

"rotation": ["math.sin(q.anim_time * 360) * 30", 0, 0]

O osso balança 30° para cima e para baixo, um ciclo por segundo.

Quase tudo em Molang começa com um prefixo que indica de onde vem o dado.

Lição 3: Operadores

Aritméticos: + - * /

q.health / q.max_health      // porcentagem de vida (0 a 1)
q.ground_speed * 2 + 1

Comparação: == != < > <= >=

q.health < 5                 // 1 se a vida for menor que 5
q.variant == 2

Lógicos: && (e), || (ou), ! (não)

q.is_on_ground && q.is_moving   // no chão E se movendo
!q.is_baby                      // NÃO é filhote

Ternário (se/senão)

condição ? valor_se_verdadeiro : valor_se_falso

q.is_baby ? 0.5 : 1.0           // escala 0.5 para filhote, 1.0 para adulto

Coalescência nula ??

Usa um valor padrão se a variável ainda não existe.

v.contador ?? 0
Variáveis não inicializadas valem 0, mas o ?? deixa a intenção clara e evita surpresas.

Lição 4: Funções matemáticas

FunçãoO que faz

math.sin(q.anim_time * 180) * 10        // oscilação suave
math.clamp(q.ground_speed * 20, 0, 80)  // ângulo limitado a 80°
math.random_integer(0, 3)               // sorteia 0, 1, 2 ou 3
Por que * 360? Como sin usa graus, 360° é um ciclo completo. Multiplicar o tempo por 360 dá 1 ciclo por segundo; por 180, 1 ciclo a cada 2 segundos.

Lição 5: Variáveis e várias linhas

v. persiste enquanto a entidade existir e pode ser lida por outros arquivos. t. some após a expressão terminar, ideal para cálculos intermediários.

v.velocidade = q.ground_speed * 2;

t.angulo = math.sin(q.anim_time * 360) * 20;
return t.angulo * 2;

Regra do return

  • Uma única expressão: o resultado é devolvido automaticamente.
  • Várias instruções (com ;): use return para dizer qual valor devolver.
"math.sin(q.anim_time * 360) * 20"             // expressão única: ok
"t.a = q.ground_speed * 10; return t.a * 2;"   // várias: precisa de return

Structs e arrays

v.pet.fome = 5;
v.pet.nome = 'Rex';

array.cores[2]       // array definido em render controller

Loops

t.i = 0;
t.soma = 0;
loop(5, {
  t.soma = t.soma + t.i;
  t.i = t.i + 1;
});
return t.soma;       // 0+1+2+3+4 = 10

Dentro do loop(vezes, {...}) você pode usar break; (sai do loop) e continue; (pula para a próxima volta). Use loops com moderação: pesam no desempenho.

Lição 6: Molang em animações

{
  "format_version": "1.8.0",
  "animations": {
    "animation.meu_mob.andar": {
      "loop": true,
      "bones": {
        "perna_direita": {
          "rotation": ["math.cos(q.modified_distance_moved * 38.17) * 60", 0, 0]
        },
        "perna_esquerda": {
          "rotation": ["math.cos(q.modified_distance_moved * 38.17 + 180) * 60", 0, 0]
        },
        "cabeca": {
          "rotation": [0, "math.sin(q.anim_time * 90) * 15", 0]
        }
      }
    }
  }
}
  • Os três valores de rotation são [X, Y, Z].
  • As pernas usam a distância andada: param quando a entidade para e acompanham a velocidade.
  • A perna esquerda soma 180 graus à fase para balançar no sentido oposto.
  • A cabeça gira levemente de um lado para o outro com o tempo.

Intensidade conforme a velocidade

"math.cos(q.modified_distance_moved * 38.17) * 60 * math.clamp(q.modified_move_speed, 0, 1)"

Lição 7: Render Controllers e entidades

Trocar textura por variante

{
  "format_version": "1.8.0",
  "render_controllers": {
    "controller.render.meu_mob": {
      "arrays": {
        "textures": {
          "Array.skins": ["Texture.normal", "Texture.vermelho", "Texture.azul"]
        }
      },
      "geometry": "Geometry.default",
      "materials": [{ "*": "Material.default" }],
      "textures": ["Array.skins[q.variant]"]
    }
  }
}

Se q.variant for 1, a textura usada é Texture.vermelho.

Tamanho de filhote (client entity)

"scripts": {
  "scale": "q.is_baby ? 0.5 : 1.0"
}

Variável pré-calculada

"scripts": {
  "pre_animation": [
    "v.velocidade = q.modified_move_speed;"
  ]
}

Assim v.velocidade fica disponível em todas as animações da entidade.

Animation Controller (transições)

"states": {
  "default": {
    "animations": ["parado"],
    "transitions": [ { "andando": "q.is_moving" } ]
  },
  "andando": {
    "animations": ["andar"],
    "transitions": [ { "default": "!q.is_moving" } ]
  }
}

A transição acontece quando a expressão Molang vira verdadeira (diferente de 0).

Lição 8: Erros comuns e depuração

ProblemaCausa provável
Nada aconteceEsqueceu as aspas: Molang no JSON é texto ("q.is_baby")
Valor sempre 0Query escrita errada ou usada no arquivo errado
Animação "pulando"Ciclo mal calculado; revise a multiplicação do sin/cos
Erro com várias linhasFaltou return
Variável vaziaDefinida em outro lugar ou momento; use ?? 0
Entidade não carregaVírgula faltando ou erro no JSON

Como depurar

  1. Ative o Content Log em Configurações, Criador, Registro de Conteúdo (GUI). Ele mostra erros de Molang e JSON.
  2. Teste valores simples primeiro (ex.: "10") antes de expressões complexas.
  3. Divida cálculos longos em variáveis t. para facilitar a leitura.
  4. Use /reload (ou reabra o mundo) para recarregar os arquivos.

Exercícios

Tente resolver antes de abrir a resposta.

1. Devolva 2 se a entidade for filhote e 1 se não for.

q.is_baby ? 2 : 1

2. Faça um osso balançar entre -45° e +45° a cada 4 segundos.

math.sin(q.anim_time * 90) * 45

Um ciclo completo são 360°; a 90° por segundo, leva 4 segundos.

3. Dê 1 somente quando a entidade estiver no chão e agachada.

q.is_on_ground && q.is_sneaking

4. Limite q.ground_speed * 100 a no máximo 90.

math.clamp(q.ground_speed * 100, 0, 90)

5. Sorteie um inteiro de 1 a 6, como um dado.

math.random_integer(1, 6)
